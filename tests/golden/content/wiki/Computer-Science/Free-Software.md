[Computer Science](_index.md) -> Free Software [#free-software](/tags/free-software/) [#info-politics](/tags/info-politics/)

Software that respects the four freedoms: run, study, share, modify. Not to be confused with "open source", which describes a development method rather than an ethic.

See [CopyLeft](CopyLeft.md) for the licensing mechanism that keeps it free.

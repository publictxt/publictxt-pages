# Project PublicTxt

PublicTxt is an experiment in using Git repositories as an interoperability layer for public knowledge: plain Markdown, free Git hosting, static site generation, and selective aggregation across repositories. [#publictxt](/tags/publictxt/) [#commons](/tags/commons/)

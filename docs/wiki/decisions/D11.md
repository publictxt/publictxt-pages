# D11 — Categories are a configured closed list, read from front matter

*Recorded 2026-09-23.*

**Decision.** A page's category is its `category:` front matter, one value, accepted
only if it appears in `params.categories.list`. Not a Hugo taxonomy; no term pages.

**Why.** Tags are already the open, emergent vocabulary; a second open one would just
be tags again. The value of categories is that they are few and curated, so the list
is the contract and a typo warns rather than minting a new category. Front matter
(over deriving from tags or paths) keeps it explicit and plain-text, and sections/
types already cover path-derived grouping. Skipping the taxonomy avoids generating
pages nobody asked for; the facets need only the value.

**Revisit when.** Someone wants `/categories/<c>/` pages or a sidebar list — then
declare it a taxonomy and keep `category.html` as the validator. Or pages genuinely
need more than one category, at which point it is converging on tags.

# D12 — A page may have several categories

*Recorded 2026-09-26. Amends [D11](D11.md).*

**Decision.** `categories:` (and the original `category:`) accept a value or a list;
the page gets their union, each value still checked against `params.categories.list`.
Category chips multi-select as OR (`?category=a&category=b`): within a facet, picking
more widens; across facets, AND. Tags stay AND, so the Category heading says "any" when several are picked.

**Why.** Real pages straddle the list (Tech *and* Science); forcing one choice made
authors pick arbitrarily. The closed list — the thing that separates categories from
tags — is kept. `category:` stays so existing pages need no edit.

**Revisit when.** Pages routinely carry most of the list — then categories are tags
with a whitelist. Tag OR (SPEC) should reuse the shape: a facet's counts computed
without that facet's filter.

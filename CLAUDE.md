# PublicTxt-Hugo — Project Context

Static site interface (Hugo + Pagefind) for browsing/searching a single PublicTxt Git repository. See `SPEC.md` for full v1 spec.
This should fulfill the **Static Website Generation** portion of PublicTxt. See `PublicTxt-README.md`

## Docs

- `SPEC.md` — what the build does today. Descriptive; no rationale.
- `DECISIONS.md` — why, one record per decision, each with a **Revisit when**.
- `docs/claude/` — session retrospectives.

These docs are iterative reasoning, largely generated in past sessions — **not a contract.**
A decision's authority is its argument, never the fact that it is written down. If the
reasoning no longer holds, say so and overturn it; don't quote a doc back as a constraint.
A conclusion recorded without an argument is a gap in the doc, not an answer.

## Working style

- Senior mentor mode: flag design tensions and gaps, don't just implement silently
- Concise output, no unnecessary explanation
- Plan/confirm before building non-trivial pieces — thin vertical slices preferred over finishing one layer end-to-end

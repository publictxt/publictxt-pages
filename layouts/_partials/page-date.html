{{/* A page's `created` date, followed by its `updated` date when the page has changed since (more than a day later). Expects a page in `.page`, and `.detail` true on single pages, where both dates are also exported as Pagefind metadata (`created`, `updated`, RFC 3339) for search result cards. The same two dates drive the whole site: lists sort on `updated` (see recent.html), and the sidebar meta block shows the same pair, so a page never reads as "18 Sep" in one place and "Updated 18 Sep" in another. */}} {{ $p := .page }} {{ if not $p.Date.IsZero }} {{ $p.Date.Format "2 Jan 2006" }} {{ if gt (int (sub $p.Lastmod.Unix $p.Date.Unix)) 86400 }} · updated {{ $p.Lastmod.Format "2 Jan 2006" }} {{ end }} {{ end }}

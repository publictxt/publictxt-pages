{{/* A browse list: a plain link list for crawlers and no-JS, which list.js replaces with cards from the site index. Names its subset, not its data. The plain list leaves out pages of a hidden collection (hidden-collections.html), as list.js does by default — unless every page is in it: a list of that collection. Client-side, not .Paginate: that fixes order and membership at build time, so sorting and filtering could only act on one page. Expects a dict: pages — the page collection, in the order the fallback should show scope — dict: kind (section | collection | tag | recent), value order — default sort (see list.js), optional filter — default chip filters, URL-spelled (list-filter.html), optional perPage — cards per page, optional (0 = list.js default) compact — true for cards only, no controls (dataview blocks) limit — compact only: show the first N, optional (0 = all) */}}

    {{ range .pages | complement $skip }}
